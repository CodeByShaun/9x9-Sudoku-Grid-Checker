# 9x9-Sudoku-Grid-Checker
This program checks a 9x9 Sudoku grid to see if it's correct. It verifies that each row, column, and 3×3 block contains no duplicate numbers from 1–9.. Zeros represent blank cells and are ignored. The functions return False if duplicates exist inside the same row, column, or 3x3 grid. Otherwise, the grid is valid and returns True.
